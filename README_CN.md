# 共享原理图增强版

[English](README.md) | **[中文]**

> **项目来源**：本项目是基于 [Syncmatica](https://github.com/End-Tech/syncmatica) 的修改版分支，在原有功能基础上增强了协作特性，包括共享材料进度追踪功能。

## 核心新增功能：共享材料进度追踪

**材料进度追踪** 为多人协作建筑提供了实时的材料协调系统：

- **需求共享**：服务端自动扫描原理图所需材料，实时同步给所有玩家
- **认领机制**：玩家可认领特定材料，避免重复收集
- **补给区扫描**：服务端可扫描配置的容器区域，追踪可用库存
- **实时HUD显示**：客户端悬浮窗口显示材料进度，支持自定义位置和样式

通过 `MaterialGatherings` 按钮打开材料追踪界面，协调团队资源收集工作。

---

Syncmatica_r 是一个旨在与 Litematica 模组集成的修改版，让原理图及其放置位置能够轻松共享。

> [!CAUTION]
> Syncmatica_r 赋予用户较大权限，可能对服务器产生影响。请仅在确信用户不会过度滥用的情况下使用本模组。

### 客户端安装

首先需要安装 Fabric，并将 Litematica 和 Malilib 模组添加到客户端。然后将 Syncmatica_r 模组文件放入 mods 文件夹即可开始使用。

### 服务端安装

对于服务端，只需安装 Fabric 并将 Syncmatica_r 放入 mods 文件夹即可。

模组首次运行后会创建配置文件，您可以根据需要进行配置。
更多信息请参阅 [配置文档](https://github.com/RMS-Server/syncmatica_r/blob/master/CONFIG.md)。

## 使用方法

在客户端安装后，您可以正常加入任何服务器。对于安装了 Syncmatica_r 的服务器，您将看到一些额外按钮：其中 2 个位于主菜单中，用于查看服务器上共享的放置并下载；另一个在原理图放置概览中，用于将您的 Litematica 原理图共享到服务器。

要加载某个共享原理图，您需要与它处于同一维度。

要修改放置，只需在客户端解锁该放置。完成更改后重新锁定，即可与所有人共享变更。
